Project Lead & Software Developer

Simple Chess Engine

Built a chess engine in Java, designed around clean object-oriented architecture from the start rather than bolted on afterward. Wrote unit tests specifically to assess and optimize engine performance, and kept documentation of the codebase accurate and current throughout.

Reflection: This project is where I first had to balance correctness against performance under a real constraint — a slow engine is a useless engine. Structuring it with OOP principles first made it far easier to isolate and fix performance bottlenecks later without rewriting core logic.

Software Developer

Python Password Manager

Built a password manager in Python with a SQLite backend to securely store and retrieve account credentials. Applied OOP principles to design the system, used data structures and algorithms knowledge to implement efficient CRUD operations, and used SQL directly for persistent, structured storage.

Reflection: This project came directly out of the belief I write about on my home page — that privacy-relevant tools should be auditable, not just trusted. Building it open source and keeping the storage and retrieval logic simple enough to actually review was the point, not an afterthought.

Aperta Academia

A simple web forum built with Python and Django. Designed and implemented the front-end with HTML, CSS, and JavaScript with an emphasis on responsive interactions, then deployed the finished application to PythonAnywhere.

Reflection: My first real end-to-end project — backend, frontend, and deployment all in one. It taught me how much of "full stack" work is really about making decisions consistently across layers rather than being an expert in any single one.
